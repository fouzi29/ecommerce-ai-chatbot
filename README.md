## ✨ Core Feature Highlights

### 🤖 1. Dual AI Engine & Smart Demo Mode
- **OpenAI API Integration**: Supports `gpt-4o`, `gpt-4o-mini`.
- **Google Gemini API Integration**: Supports `gemini-2.0-flash`, `gemini-1.5-flash`.
- **Smart Demo Mode**: Intelligent offline fallback engine with catalog awareness. Evaluates product searches, promo codes (`AURA20`), shipping policies, and order tracking out-of-the-box **without needing any API keys**!

### 🛒 2. Direct AI Order Placement & Lead Collector Engine
- **In-Chat Direct Order Placement**: Shoppers can order products directly inside the AI chatbot window (`#AU-9942`) with real-time database recording.
- **In-Chat Lead Collector Form**: Captures customer name, email, phone number, product interest, and custom inquiry notes.
- **Full Admin Orders & Leads Dashboard**: Accessible via the `Admin DB` button, featuring real-time revenue analytics, order management, lead management, and **CSV Data Export**!

### 🔌 3. Database & Platform Sync (SaaS Client Panel)
- **Multi-Source Database Integration**: Configurable for **Custom REST APIs** (MySQL/Node/PHP), **Shopify Storefront API**, **WooCommerce REST API**, or **Supabase PostgreSQL**.

## 🚀 Quick Start Guide

### Prerequisites
- Node.js `v18+` or `v20+` installed.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/fouzi29/ecommerce-ai-chatbot.git
   cd ecommerce-ai-chatbot
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start local development server:
   ```bash
   npm run dev
   ```

4. Open your browser at `http://localhost:5173`.

---

## 📤 Deploying to Vercel

1. Import repository on [Vercel](https://vercel.com).
2. Framework Preset: **Vite**.
3. Click **Deploy**.
